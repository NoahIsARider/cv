Academic CV of Fangyanuo Zhou.

Published at https://noahisarider.codeberg.page/cv/ — English at the root, 简体中文 under zh/, 繁體粵語 under yue/.
This repo is self-contained: the headshot (photo.jpg), the CV PDFs (CV_English.pdf, CV_Chinese.pdf), the
portfolio (Portfolio.pdf) and the CMLE paper (CMLE_IEEE_TCE_2026.pdf) all live here, and every page links
them relatively. The main site keeps its own copies for its own pages.

The pages carry a day / night switch, `theme.js`. Paper is the default; a reader's pick is kept under
`nc-theme` and travels with them across every page of the site. The sidebar is pinned to 210px so it
does not move when the language changes, and `theme.js` names no host, so the same file serves every
mirror. The night palette is jemdoc's own pushed dark, not the main site's solarized one.
